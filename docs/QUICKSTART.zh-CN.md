# 第一次使用 Muse

此教程面向同款 FoloToy AI Passport，不要求会编程。目标是“联网 → 保存自己的 Token → 手机配对 → 云端就绪 → 发语音 → 看文字”。刷机替换整机玩法，不是安装插件。

## 0. 下载对的文件

1. 打开 [官网口袋百宝箱玩法页面](https://ai-passport.folotoy.cn/plays/438/)，确认版本说明中包含 Muse；如果尚未上传对应固件，先等待维护者更新。
2. 按官网流程下载/刷入适配同款设备的固件。本 GitHub 只放 Muse 功能源码和教程，没有可刷写整机 BIN；Source code ZIP 不能刷机。
3. 先阅读 [固件与备份注意](FIRMWARE.zh-CN.md)；已经安装含 Muse 的同版固件时不用重复刷。
4. Muse 不需要运行 windows/start.cmd，不需要 VB-CABLE 或微信输入法；它们属于另一个电脑打字功能。

准备数据 USB 线、电脑、手机、设备、可用 Muse 账号和 2.4 GHz Wi-Fi。使用电脑代理时电脑须持续开机；设备网络可直连时不依赖电脑。

## 1. 提前准备手机和账号

安装并登录手机 Muse，确认能正常发送文字请求。在浏览器打开 [Muse Gadget 网站](https://gadgets.muse.ai/)，按官方页面申请自己的 SDK Token，阅读其条款。Token 格式通常以 `mgst_` 开头；账号没有此入口或权限时，需要先向官方确认，刷固件不会开通账号资格。

先准备 Token，再连接设备热点，因为设备热点本身不提供互联网。不要在 GitHub Issue 或截图中公布 Token。

## 2. 让设备连接 Wi-Fi

首次无网络记录时自动打开手机配网页。手机在系统 Wi-Fi 列表连接设备屏幕所示热点，再用浏览器打开屏幕所示地址。若手机提示“没有互联网”，保留这条连接，不要自动切回其他 Wi-Fi。

在页面扫描并选择 **2.4 GHz Wi-Fi**，填写密码并保存。已有配置的设备可从首页长按下键进入手机设置，也可以在设备设置中打开手机设置。不要用手机系统蓝牙页面配对 Muse。

个人资料、姓名、签名、地址、头像或名片都是可选项。Muse 接入不要求上传这些内容。

## 3. 填写 Muse 配置

手机设置页进入“个人资料”，展开“Muse 语音助手”：

1. 在 **SDK Token** 粘贴自己申请的 Token。
2. 能从设备直接访问 Muse 时，**电脑代理 IP 和端口留空**。
3. 普通 Wi-Fi 不能直连时，按 [电脑代理教程](NETWORK.zh-CN.md) 填写自己电脑的局域网 IPv4 和 HTTP/混合代理端口。
4. 点击“保存 Muse 配置”，看到成功提示后完成设置并退出热点。本版主完成按钮也会保存修改过的 Muse 配置；失败时保留页面，请先处理提示。

已有 Token 时，输入框留空会保留它；更换 Token 会清除本应用旧配对，之后需要重新添加设备。只修改代理不会解除配对。已保存 Token 不回显，输入框变空是正常情况。

当前页面提供手动配置，尚未提供自动发现代理或电脑配置助手。公开构建默认直连，不含维护者代理地址。

## 4. 在 Muse App 绑定自己的设备

完成手机设置后，让手机恢复正常联网，硬件回到自己的 Wi-Fi。打开设备 Muse，等待显示“等待配对”。

1. 手机 Muse → **设置 → 设备**，启用开发者模式。
2. 点击添加设备，选择 `MuseGadget-Passport-XXXXXX`，核对硬件页面的尾号。
3. 硬件显示“是你的手机吗”时，短按一次确定键。
4. 手机要求选择 Wi-Fi 时，选**设备当前已经连接的同一个 Wi-Fi**。本项目复用整机网络，只向手机提供当前网络；先在手机设置页换网络，再重新配对。
5. 手机添加成功后，等待硬件显示“我准备好了”。手机出现设备条目表示授权保存；硬件仍需连接云端。

App 不同版本可能调整入口和文案，以实际官方界面为准。后续开机保留 Token、配对和网络记录，不需要每次重新添加。

## 5. 第一次说话

设备屏幕亮起并显示“我准备好了”后，按住上键；看到“我在听”后说“只回复测试通过一二三四五”，约2～3秒后松开。第一次按键如果仅唤醒屏幕，请在亮屏后再次按住。

松开后应显示思考状态。核对手机 Muse 收到语音，并等待硬件出现文字回复。回复多页时短按确定翻页。Muse 可能先发“还在处理”再给最终结果，期间保持应用打开，不按下键、不启动下一段录音。

每次最长录音30秒。短按下键取消本地等待或录音；已经提交给 Muse 的任务可能继续执行。长按确定返回应用列表，释放本应用资源。

当前没有声音播报，屏幕文字就是本功能的输出。只保留最新回复前 1023 个 UTF-8 字节（纯中文约 341 字）；长回复去手机查看。

### 首次验收表

| 检查 | 完成标志 | 未完成时 |
| --- | --- | --- |
| 设备联网 | 已连接自己的路由器 | 检查 2.4 GHz、密码、信号 |
| Token 保存 | 手机页报告保存成功 | 不回显旧 Token 是正常保护，不要反复替换 |
| 手机配对 | Muse 内出现相应设备尾号 | 检查权限与实体确认，别在系统蓝牙页添加 |
| 云端连接 | 硬件显示“我准备好了” | 已配对不等于云端可达，检查网络出口 |
| 第一次发送 | 手机收到语音、硬件显示相关回复 | 保持页面等待最终结果，查看错误提示 |
| 第二次发送 | 上次最终回复后再发，仍能收到回复 | 不同时等待旧任务又开始新录音 |
| 退出再打开 | 不重新配对也能连接 | 检查代理仍运行、IP/端口没变 |

用无敏感信息的测试句。不要让自动化工具把周围环境声音当作任务发送。

## 6. 换网络或转让设备

更换 Wi-Fi：退出 Muse，进入手机设置更新网络；原账号授权通常可保留。电脑代理 IP 变化时更新 IP 和端口即可。电脑 IP 可在自己的路由器上设置 DHCP 地址保留，减少后续改动。

解除 Muse：优先在手机 Muse 设备管理中移除，然后在硬件错误页长按下键清除配对。SDK Token 是单独配置，不随配对清除；转让硬件前需撤销自己的 Token 并清除个人资料及整机网络记录。恢复出厂/全盘擦除会删除更多数据，不能作为普通连接失败的第一步。

常见失败按 [网络排查](NETWORK.zh-CN.md) 逐层检查。没有虚拟声卡或微信输入法步骤；这两项属于另一个“AI语音输入”功能。

## 7. 三个常见误区

- 已配对仍失败：配对、云端连接是不同步骤。区分 DNS、代理连接、明确授权拒绝，不先删账号。
- 手机能使用不代表设备能用：手机网络通道不会自动共享给 ESP32；蓝牙在本项目中不转发云端流量。
- 没有播报不代表失败：本版 Muse 是语音输入、文字输出，不按小智的播报预期判断。
