# 用 Codex 等 Agent 辅助配置

统一流程已移至 **[Agent 配置手册](AGENT_SETUP.zh-CN.md)**。原链接保留，Codex、Claude Code、WorkBuddy 等本地 Agent 均可按实际工具能力使用。

1. 下载并完整解压本项目，在待配置电脑的 Agent 中打开项目根目录。
2. 复制手册第一节的指令；Agent 会检查已有功能、电脑网络和配置进度。
3. 按提示在本地设备设置页填写自己的 Token，并完成手机配对及硬件确认。
4. 硬件显示“我准备好了”后亲自说话，完成两次回复与退出重进测试。

账号资格、系统授权和实体操作仍需用户参与。电脑端诊断不代表设备已联网或 Muse 已回复。换网/重启后重新检查 IP 和代理，不反复清空授权。

不使用 Agent 可照 [完整使用教程](QUICKSTART.zh-CN.md) 和 [网络教程](NETWORK.zh-CN.md) 手动配置。本仓库不是可刷写固件，固件入口见 [说明](FIRMWARE.zh-CN.md)。
