# 用Codex辅助配置

适合本机Codex等具备读取文件、执行命令能力的工具。网页聊天无法直接配置你的电脑或USB硬件。以下指令用于检查和辅助，不替代自己的Muse账号、可用网络出口和本人配对确认。

先下载本仓库到电脑，再在该目录打开Codex。复制：

```text
请帮助我配置本仓库的AI Passport Muse，先完整阅读README.md以及docs中的使用、网络、开发和验证说明。

我的设备是同款FoloToy AI Passport。本仓库只公开Muse功能模块，不是可单独构建的整机。普通使用请从README指定的官网玩法页获取含Muse的固件；页面尚未更新时明确说明等待维护者，不要拉取私有整机仓库。不要把Source code ZIP当固件，不要猜端口或把应用镜像写到0。

检查我的网络：优先使用设备能访问Muse的Wi-Fi；不能直连时，读取已有代理的HTTP/混合端口和当前局域网IPv4，帮助我填写自己的配置。不要使用作者的代理地址，也不要安装或替我购买网络服务。修改代理局域网监听和防火墙前，把具体范围与影响告诉我，由我确认；不要关闭整个防火墙。

SDK Token由我在官方网页申请并亲自填写到手机设置页，请不要让我贴到聊天或日志。我的Token、配对记录、Wi-Fi密码、备份和对话内容都不要上传到GitHub。

烧录前核对设备、芯片、Flash大小、分区、待烧录文件和已有数据备份。不要全盘擦除或覆盖其他设备；需要改变现有系统或清除数据时先让我确认具体操作。

引导我完成：手机连接设备热点、填写Wi-Fi和Muse配置、退出热点恢复联网、在手机Muse开发者模式添加设备、在硬件按确定确认。确认“我准备好了”后，让我按住上键说“只回复测试通过一二三四五”并松开，核对手机收到语音、硬件收到文字以及内存/连接日志。

不要为了测试自动把环境声音提交成任务。可做取消前的录音测试，真正语音发送由我操作。最后分别报告编译、网络、配对、实际发送、硬件回复和内存验证结果，未做的项明确写待验证。
```

本人仍需完成官方账号登录与条款、申请Token、管理员确认、实体配对按键和实际说话。当前仓库没有一键代理发现工具或桌面配置助手，Codex应依据你本机已有软件检查，不能声称已自动打通设备网络。

如果刚重启电脑或换了Wi-Fi，重新检查IPv4、代理运行状态和局域网互通，不要重复清空Muse授权。
