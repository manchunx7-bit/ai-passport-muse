## 历史集成与设备记录

本仓库是功能源码拆分，不是整机固件工程。官网 `0.2.0-rc.7` 保持既有 Muse 业务逻辑，并将固件内角色切换为官方 Jollybot；本仓库不包含其他应用、底层宿主实现、整机 BIN 或 Jollybot 美术源文件。

该集成固件在用户保存自己的代理后，保留配对连接成功。一次无按键干扰的测试完成 5 次录音提交、收到 4 次文字回复，回复耗时约 6.54–9.09 秒；首轮未在下一次录音前收到回复，不能写成 5 轮完整对话。录音采样最低空闲堆 29,604 B，最大连续块最低 18,432 B，未见内存申请失败、TLS 内存错误、任务退出超时或重启标志。

应用模块的 host 测试覆盖 11 项聊天协议/错误场景和 WAV/base64/UTF-8 边界。`0.2.0-app.2` 发布准备期间已在拆分后的目录重新执行通过；GitHub Actions 记录对应提交的实际结果。CI 不使用 Token、不发送环境音。

官网 `0.2.0-rc.7` 使用 ESP-IDF 5.5.3 独立发布配置编译通过，确认启用 Jollybot、空代理默认值，应用分区和 `0x0` 合并镜像结构校验通过。相同 Jollybot 应用镜像已在目标设备显示验证；为避免覆盖设备现有 NVS，本次没有再次用完整 `0x0` 镜像执行空配置首次安装。

**未验收：** 完整 `0x0` 镜像的空配置首次安装、跨账号/网络/手机兼容、长时老化、语义准确率及跨版本服务行为。普通用户应使用官网已集成的固件；此仓库没有可刷写 BIN，也不把 Source code ZIP 当固件。

原始串口日志、配对材料、完整 Flash 备份和对话不公开。公开版默认代理为空，需要使用自己的网络配置。
